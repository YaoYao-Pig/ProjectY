# 大地图低多边形风格

先看 [资源清单与接入](../../../ForAI/Business/MapArt.md)，从清单定位现有 `.blend`、模型实测尺寸和预览。实际建模、导出、Unity 导入沿用 [blender-unity](../blender-unity/SKILL.md)；本技能只负责美术选择和视觉验收。

## 画面与形体

- 目标是斜俯视大地图中的朴素暖色乡镇：大块面、清晰剪影、低饱和自然色，材质不抢过地形与建筑轮廓。用几何体和颜色表达体积，保留平面法线与硬边。
- 先缩到地图使用尺寸判断是否可辨认，再补近景细节。避免细瓦片、密窗棂、砖缝、写实噪点贴图、金属高光与装饰堆叠；这些不应成为识别建筑的主要依据。
- 民居以小体量和高坡屋顶为主；工坊以较高墙体、低坡屋顶与烟囱区分；集会厅以宽大体量、较高屋脊及明确入口区分。门窗用少量深色面，木梁只强调结构，不画黑色描边网格。
- 中世纪城堡以角塔、垛口城墙、拱形城门和中央主堡构成剪影；塔身用少边圆柱，石墙保持大块纯色。主堡延续赤陶坡屋顶，旗帜只作少量识别点；整体作为一栋完整建筑落在连续多格平台上。
- 地牢入口用粗石拱门、暗洞、下行台阶与破损侧柱区别于民居；保持单格范围，不制作室内关卡。旧石塔遗址可作为其他遗迹资源保留；Web 占位轮廓也应体现石拱，避免套民居屋顶。暗洞背板使用有厚度的封闭网格，避免 Unity 单面材质下消失。
- 地牢内部以完整的功能设施丰富空间：宽祭台、成组石棺、长桌与长凳、货垛、书架、连柱廊、岩石和根系组合。大型物件共享连续底座，大小件有层次，不把同一单格模型简单放大来填满房间；保留大块硬边和低饱和材质。模型应落在配置的完整多格占地内，摆放朝向与占地旋转一致；战斗净空和通道宽度由算法控制，美术不自行缩窄。
- 隐居群落使用明显低于普通民居的矮屋：低墙、宽而低的木色屋顶、石基与少量门窗，不增加楼层和高烟囱。每栋房屋仍是完整单格建筑，分散组成群落；生成净距与道路关联归配表，不由模型决定。
- 森林以不对称块面阔叶树和分层针叶树构成，少边树干、无叶片贴图；覆雪松树保留深绿色裙边，避免与白色地面融为一体。
- 地形底块保持精确六边形边界，变化主要来自地图高度、地貌色和可拆山石。不要随机移动拼接顶点、把边缘倒角成缝隙，或在每块地形上重复相同山峰。
- 水面单独成层，用连续平整蓝色面表达；不要烘焙固定岸线或在每格画边框。地面高度、水位和水域范围继续由地图数据决定。
- 城镇保留分散建筑地块与地块间自然地面。大建筑占地使用真实多格合并轮廓、连续平台和单个完整建筑；内部不露格缝。不要把整个城镇连成一张铺满的底板。

## 配色与材质

以下为本套风格的 sRGB 基准；同组可作少量明暗差，不用随机高对比花色。已有材质名和具体分配以资源清单为准。

| 用途 | 色彩基准 |
| --- | --- |
| 草地 | `#759754` |
| 石质山地 | `#9e9685`、`#898379` |
| 湖岸、河岸 | `#849c66`，河床可偏冷、偏暗 |
| 水面 | `#4da5b2`，深水参考 `#246384` |
| 森林与树冠 | 地面 `#567747`，阔叶 `#557c43`，针叶 `#3f6b57` |
| 冰雪 | 地面 `#d7e4e6`，侧面 `#a2b7ba`，积雪 `#e8efea` |
| 城市地块 | `#bca27b`，侧面 `#948365` |
| 建筑墙面 | `#ded0ad`、`#c9b994` |
| 赤陶屋顶 | `#a8694e`、`#875241` |
| 木构、门窗 | `#66594a`，窗洞可更暗 |

- 当前资源使用纯色哑光材质，无贴图依赖；材质按用途共享，避免每个对象复制一份。光照负责大部分明暗，色槽只补充主要面层次。
- Blender 输入正确的颜色空间；向 Principled Base Color 填十六进制颜色时先从 sRGB 转线性。Unity 独立材质按当前 Built-in 管线设置并核对实际颜色，不依赖 Blender 节点自动迁移。
- 不把美术深浅误当高度或通行规则。城市等级未来可通过轮廓、尺寸、屋顶或少量标识扩展；当前不要擅自添加等级、玩法或室内规则。

## 尺度与交付检查

- 以当前配表与资源实测尺寸为准，新增建筑先核实占地和高度。外挑屋檐、台阶、烟囱也计入包围盒；单格建筑不能伸入邻居地块。
- 保持米制、落地原点与统一正面；Unity 为 +Y 上、+Z 正面。保留可编辑源文件，展示布局使用副本，导出原件不带展示位置偏移。
- 山石可以不对称，但拼接底块保持精确；相邻材质接壤依靠地图的地貌权重或后续混色表达，不把一种固定 Region 接缝做死在模型里。
- 按受影响范围实际查看斜俯视整体，并与现有建筑同框对照；涉及地形时检查相邻地块接缝、七格城市平台和水陆层次。检查剪影可辨、没有内部格线/漏底/穿插，纯色没有粉红缺材质或意外发亮。
- 报告真实完成的 Blender 和 Unity 检查层级。风格规则以最终实物为依据；资源目录、配置映射、导入证据与使用方法维护在资源文档，避免这里复制操作日志。
