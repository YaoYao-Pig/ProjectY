# ForAI 按需读取

1. 在当前项目按已有 AGENTS 指引定位 `ForAI/INDEX.md`；路径未知时先查当前目录及父级，不全盘搜索。没有 ForAI 时说明未找到，沿项目现有文档继续，不虚构入口。
2. 读取 INDEX，用任务关键词选择最相关的一篇模块文档；跨模块问题才追加对应文档。默认不读维护约定、历史验证、完整架构或全部目录。
3. 从模块“关键入口”定位路径和符号。需要了解或修改实现时，在这些路径内用 `rg -n` 找符号，再读相关函数及必要调用方。文档索引没有命中时，先对可能的源码目录做定向搜索。
4. 足以解释问题或确定修改范围即停止扩读；新增阅读应回答具体缺口，如数据归属、调用来源、生命周期或验证方式。不要递归展开链接，也不预读生成物、第三方或缓存。
5. 文档可路由，代码确认行为。发现矛盾按代码核实，修正有关文档；不要把历史测试结果或计划中的能力当作当前事实。

输出结论时给必要入口与未解问题，不复述已读取的整篇文档。涉及文档维护时再读项目 `ForAI/MAINTENANCE.md`；本技能不保存项目知识副本。
