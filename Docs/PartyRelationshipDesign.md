# 队员关系系统：首版设计与落地
更新：2026-11-02。本文区分已实现能力与后续设计；当前运行契约以 [PartyStory](../ForAI/Business/PartyStory.md) 为准。

## 设计目标

让玩家记得“这两个人一起经历了什么”。关系由具体行为积累，经历留下人物、时间、地点与实际变化；坏关系可以修复，友情可以完整发展，恋爱由明确选择确立。

首版采用一份双方共享的好感、一份芥蒂、独立的爱恋标记与有方向的事件纪事。无向好感沿用项目已有存档模型；谁误伤谁、谁救了谁仍精确记录。单向暗恋、敬重与依赖暂不模拟。

## 参考依据与取舍

| 参考 | 已核实的机制 | 本项目采用的思路 |
| --- | --- | --- |
| 《我们的冒险者公会》 | 开发者说明恋爱还需要匹配的偏好、双方兴趣；满好感不保证建立恋爱。[开发者回复](https://steamcommunity.com/app/2026000/discussions/0/603016959722783092/) | 把好感与恋爱身份分开。首版由玩家确认双方心意，条件透明，不等待隐藏随机数。 |
| 《漫野奇谭》Wildermyth | 朋友、恋人、对手是不同关系，随共同行动发展，并有不同战斗效果。[官网 Wiki](https://wildermyth.com/wiki/Relationship) | 友情和爱情都是完整的发展方向，保留关系背后的共同故事。首版二者没有属性强弱之分。 |
| 《暗黑地牢 II》 | 关系影响战斗协作；旅店提供改善关系的机会。[开发商介绍](https://www.darkestdungeon.com/darkest-dungeon-2/about/) | 战斗中的行为与战外修复形成闭环。首版以可解释的纪事和主动交流为主，后续再增加支援技能。 |

下列分值、芥蒂与限次均是本项目的原创平衡方案，不是上述游戏的原始数值。

## 已实现：五档关系与爱情分流

| 好感范围 | 阶段 | 表现 |
| --- | --- | --- |
| −100～−61 | 仇恨 | 很深的裂痕；依然履行玩家的战斗指令 |
| −60～−21 | 厌恶 | 心存不满，需要持续修复 |
| −20～29 | 一般 | 初始为 0，在同行中相互了解 |
| 30～59 | 友好 | 愿意亲近、分享见闻 |
| 60～100 | 挚友／爱恋 | 自动达到挚友；爱恋需要另行确认 |

升级、降级都会留下关系变化纪事。保留旧版 30、60 的正向门槛，旧档分值原样迁移，既有经历不会改写。

确认爱恋需要双方存活、好感至少 60、共同取胜至少三次、芥蒂为零、双方均没有当前伴侣。界面先展示后果，再确认执行。没有随机表白失败，也没有为了属性强度强迫玩家安排恋爱。

好感下降或出现芥蒂时，爱恋显示疏远状态，仍保留伴侣约定；玩家可选择回到朋友关系，分值不被额外惩罚。伴侣亡故时显示追忆，幸存者可选择“珍藏回忆，继续前行”，保留共同历史并解除当前伴侣占用。首版不额外推断角色性向或相互吸引力，这些要等角色人格数据完整后接入。

## 已实现：行为如何改变关系

| 行为 | 默认好感变化 | 条件与限次 |
| --- | --- | --- |
| 普通治疗 | 首次 +3，第二次 +2 | 正式战斗；不同队员；实际有效恢复至少目标最大生命的 5%；每场每对两次 |
| 低血救援 | +12 | 扣除友伤来源后，治疗前生命不高于最大生命 25%；与死门救援共享每场每对一次 |
| 从死门救回 | +20 | 治疗前真实生命为 0，实际恢复到正数；不重复叠加普通治疗与低血奖励 |
| 协同攻击 | +3 | 两名实际参战队员在同轮先后对同一敌人造成直接伤害；每对每轮一次、每场两次 |
| 共同胜利 | +2 | 真实参战且双方存活；有本场友伤的该对不给好感，但仍记录共战次数 |
| 误伤 | −2～−18 | 随真实结算伤害占最大生命比例增加；打入死门取最大损失，同时积累芥蒂 |
| 聊聊近况 | +3 | 战外，双方共享每日一次交流机会；有芥蒂时只 +1，并消解 1 点芥蒂 |
| 坦诚道歉 | +2 | 必须存在芥蒂；减少 8 点芥蒂，与其他交流共用每日机会 |
| 确认／结束爱恋、珍藏回忆 | 0 | 改变关系身份，保留好感，使用当日交流机会 |

普通照料面对“傲慢／孤僻”特质时少获 1 点；危急救援不受这项性格减益影响。沿用原系统的真实救援成长：获救者克服配置指定的傲慢／孤僻，救援者累计三次获得守望者荣誉。阶段与爱情身份本身暂不授予额外伤害、防御或自动追加攻击。

“协同攻击”目前指同轮有效集火，不代表已经增加了一个自动追击技能。未命中、零伤害、周期伤害、传奇共债的间接传导均不计入。

## 已实现：芥蒂与反刷约束

芥蒂范围 0～100，误伤会留下额外修复成本。有芥蒂时治疗／救援好感收益减半并向下取整、最低 1；日常交谈只获得少量收益。道歉可以更快化解芥蒂，干净地共同获胜也会缓解 1 点。一次治疗不会抹去伤害的记忆。

- 同一对队员发生友伤后，本场后续彼此治疗、救援、协作和胜利均不给正向关系收益；已经发生的真实好事不会被追溯撤销。
- 目标承受的己方／自伤生命损失形成当场治疗债务。任何治疗先偿还这部分伤口，剩余的有效恢复才可能计为帮助，第三人不能接手刷“人为制造的救援”。
- 部署治疗、自疗、周期治疗、满血治疗、旁观者和动物不获得队员关系奖励；坐骑生命变化不冒充骑手本人受伤。
- 多段攻击不能重复登记同一攻击者，同一对打多个敌人也受每轮及每场协作限次。
- 普通治疗最多两次，救援一次，协作两次；不含性格与芥蒂修正时，每场每对正向收益最多 33 点（含一次死门救援与胜利）。
- 每日交流次数以无向角色对保存，换人、重开界面、场景切换和存读档都不能重置。
- 不通过后台随机吵架让关系持续雪崩；仇恨也不会自动拒绝救援、丢弃装备或杀害队友。

## 玩家入口与体验示例

入口：旅人手记 → 属性加点／总览 → 右侧“旅途印记” → 点击队友关系标签。

玩家可以看到好感、芥蒂、共战／救援／照料／协作／误伤次数及最近三条共同记忆。详情可滚动，完整事件在“旅途经历”中查阅。所有行为选项都能查看，不满足条件时显示具体原因；确认按钮固定在首行。

例如：诺拉替艾岚处理一次普通伤口，得到少量好感；后来艾岚在死门中被诺拉救回，这次救援留下更重的关系记忆。另一战诺拉误伤艾岚，即使两人已有深厚友情，也会留下芥蒂。玩家可以安排坦诚道歉，并通过后续无误伤的战斗和交流修复。两人最终可以一直保持挚友，也可以明确选择成为恋人。

## 后续设计：增加人物性格与故事厚度（未实现）

建议按以下顺序继续，而不是先堆叠全队属性加成：

1. **共同记忆标签。** 在真实事件上形成“救命之恩”“曾经的误伤”“从不留人独自断后”等有限、可解释的记忆。普通记忆逐渐淡化，重大记忆长留。事件选择可以引用具体往事，避免重复播放同一句感谢。
2. **有方向的信任与敬重。** 保留玩家熟悉的五档总览，内部区分“我喜欢你”“我相信你会救我”“我认可你的本领”。允许嘴上不合但认可实力的竞争伙伴，以及获救者感激、救助者仍然冷淡的关系。
3. **性格驱动的交流。** 将角色人格接入真实事件：谨慎者更在意冒险施法，骄傲者更重视公开认可，孤僻者更偏好并肩守夜。情境改变反馈，不用隐藏性格惩罚覆盖掉玩家刚做的好事。
4. **短篇关系事件。** 使用现有叙事系统承接争执、道歉是否被接受、共同回忆、友谊确认和悼念。每段提供两三个明确选择，结果能追溯到真实往事，而非凭空编造过去。
5. **有限支援动作。** 挚友／恋人共用同等预算：解围、提醒、掩护或协同反应，每战限次，使用已有行动经济。负面关系优先减少额外支援，保留玩家基础指令的可靠性。
6. **营地活动与三人关系。** 共同做饭、值夜、练习和调解可消费有限营地时间。三人事件先从“劝架／替人解释”开始，再评估嫉妒与竞争；不把恋爱复杂度强加给所有玩家。

未来人格与剧情接入应复用同一关系状态和纪事，而不是另外维护一份好感。需要先确定的边界包括：哪些角色允许恋爱、偏好来源、亲属关系、剧情锁定关系，以及重大背叛是否需要特殊的修复任务。
