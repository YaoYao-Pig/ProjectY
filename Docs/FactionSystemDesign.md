# 势力关系与大地图冲突系统设计

2026-10-23。本方案已接入代码、配置与大地图模型；当前契约和验证入口统一维护于 [ForAI 势力模块](../ForAI/Business/Factions.md)。

组织拥有真实据点与队伍，外交决定交战资格，局部实力、收益、路程、威胁与留守需求决定行动。NPC 交战产生可介入战场；玩家介入使用已发生的伤势，不能重新抽取满血敌人。

## 已确认的玩法

- 据点被攻陷后停止交易、居民交互和招募。玩家进入原地点，击败占据者后解放；随后商品与可招募 NPC 从较少数量逐渐恢复，原据点与任务 NPC 身份不替换。
- 玩家与盟军绿色，盟军由 AI 控制；主要敌方红色；独立第三方黄色，即使第三方敌对也保持黄色。攻击与治疗按实际双边关系判断。
- 其余组织初值、算法参数、持续时间和模型样式按用户授权确定并配置化。以下公式和数值是本项目选择，不是参考游戏公开的原始数值。

## 实际结构

现有三个叙事组织保留稳定 ID；铁牙战团、草刺部族、高树林庭与灰路匪帮承担领地行为，巨狼与岩石巨兽作为野生生态。种族、组织、外交、玩家控制权各自独立。同盟不传递，两个同样攻击敌人的中立组织不会因此自动变成能互相治疗的盟军。

C# `WorldPartiesData/WorldFactionsData` 保存可变事实，Lua `FactionRules/WorldFactions/WorldConflicts` 分别负责评分、战略和冲突。地图布局保持只读；新据点用持久旅行地点追加，既有城镇和原存档世界不会因外交变化而重生成。

角色编制只归世界队伍保存一次。战场使用同一批 Actor，存档用 PartyId 重连；伤亡、货物与掉落不会因为玩家进出或存读而刷新。旧版已有战场通过迁移收用原 Actor。

## 战略评分

势力总实力汇总真实成员的当前战力；具体攻击使用当地出动战力，考虑目标守军与据点防御。总实力强不代表一次远征就值得发动。

`局部优势 = 进攻队当前战力 / max(1, 守军当前战力 × 据点防御系数)`

先排除关系不允许、不可达、超程、留守不足、补给不足、保护期与路线威胁过高，再计算：

`行动效用 = 优势曲线 × 收益曲线 × 行程曲线 × 安全曲线 × 行动偏好`

保留当前目标有评分优势；无效目标清空旧行军路线。巡逻围绕真实据点，弱队避开强守备；受伤和携货队伍返乡，花费有限补给恢复。劫获货舱保持物品身份，送回基地后消耗为储备，不把同一件装备同时留在地面和货舱。

## 战场与据点恢复

冲突流程为：接触、交战、结算、遗迹、到期。NPC 队伍必须在可达接触范围交战，不能隔河凭直线距离开战。同一队伍只能加入一场冲突。

后台战斗默认在 45 分钟的介入窗口后推进实际伤亡，最多持续 150 分钟。玩家加入则暂停后台结算，由战术战斗继续；结束后保存剩余生命、队伍状态和真实货物。原战场默认再保留 24 游戏小时，正被玩家使用的区域等离场后到期。

| 玩家与原双方关系 | 结果 |
| --- | --- |
| 与 A 合作、与 B 敌对 | 帮助 A，A 由 AI 控制 |
| 与 A、B 均敌对 | 三方混战 |
| 与 A 中立、与 B 敌对 | 可以打 B，A 保持独立黄色第三方 |
| 与双方都不敌对 | 保持中立，不因加入按钮自动宣战 |

NPC 打赢城镇后留下占据者并封锁服务。玩家进入该原地点会在同坐标进入解放战；胜利后恢复原城镇服务，提供 24 小时免袭期。商品与可招募 NPC 从 35% 逐步恢复，72 小时达到完整；商店库存按每个补货实例和每次解放幂等削减，反复开店或读档不会重复损毁或刷出商品。

## 当前边界与验证

当前世界冲突由两支 NPC 队伍构成，玩家可作为第三方加入；没有追加第四支 NPC 援军的调度。关系支持配置和运行时覆盖，尚无自动谈判/和平条约生成。战场到期隐藏入口但保留历史身份数据，不是无限历史数据的内存回收实现。

已运行外交/战略、服务恢复、多方战斗的定向 Lua 检查，真实 Data 的存档/货物/幂等检查，以及独立临时远征的后台交战、玩家帮助、三方混战、NPC 攻陷、玩家解放和存档往返。项目集中主动编译一次，未进入 Play 或全量构建。长时间生态平衡、持续战争节奏和玩家操作体验仍需实际游玩验收。
