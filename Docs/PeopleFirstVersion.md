# 世界人物与培养首版

本版把普通居民、可交涉的人形世界成员和己方角色接到持续保存的人物档案。角色培养继续使用原有职业、属性、技能、装备和身体规则，招募改变归属，个人经历再提供成长选择。

## 可以怎样体验

1. 进入城镇，靠近普通居民按E。人物会介绍自己的来历、动机和熟人；“看看你需要帮忙的事”继续打开原有居民委托。
2. 根据动机选择招募路线。可支付安家预支、完成委托取得信任、安排有技艺的同伴指导、保障故乡道路安全，或让熟人一起同行。选项下会显示尚缺条件。
3. 也可在“单位详情·侦察”中选中人物，点击独立的交谈按钮。观察仍使用原来的侦察检定，交谈不会消耗侦察机会；未入队居民需要先走近。
4. 大地图上主动追上一支非传奇、尚未交战、包含多名活着成员的人形队伍，可以选择与成员交涉。战阵认同要求两场正式胜利、足够等级的同伴和解除旧约的费用；成功后保留原角色与装备。
5. 入队后在单位详情选择这位同伴，进入“交谈与培养”。真实共同胜利、危急救援或正式学习会开放个人成长选项；每阶段二选一，界面展示所需经历和实际收益。
6. 保存并继续远征，姓名、动机、熟人、信任、原有伤势与成长选择持续保留。普通居民入队并结束交谈后，从原城镇位置离开。

## 本版内容

- 四类动机：重新谋生、寻找师友、守护牵挂、战阵认同。
- 24个配置姓名；动机按居民类型和稳定种子选取，同城自由居民形成真实熟人配对。
- 四类个人成长各两阶段，共8阶段16个选择及16个独立经历特质。第二阶段替换本人第一阶段特质，并获得对应技艺；已掌握技艺会说明，仍能获得新特质。
- 委托与熟人帮助影响信任；本人未完成的已接委托会阻止离开。后续委托不再选已经入队的居民。
- 原有4出战、6后备容量与自由职业培养继续适用。新功能不要求重开世界；旧存档的人物档案从首次接触开始建立，不补造过去经历。

## 首版范围

城镇服务岗位保留职务，剧情人物保留原招募剧情；动物沿原有驯服路线。敌方交涉限主动接触、未绑定战场的世界队伍，最后一名存活成员暂不离开原编制。当前没有通用俘虏、随机背叛、复杂家族网络或NPC自主升级。

## 参考采用方式

- 《看门狗：军团》：人物动机、熟人影响和招募机会。
- 《漫野奇谭》：配置事件选择与持续人物变化。
- 《战争之影》：敌人转为同伴时保留能力与交锋对象身份。
- 《战场兄弟》：出身和特质影响培养判断。
- 《环世界》：身体、装备、关系与人物身份持续存在。
