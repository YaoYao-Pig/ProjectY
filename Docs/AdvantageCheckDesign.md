# 优势判定设计

日期：2026-10-25。状态：首版已接入源码，定向 Lua 检查通过；未进行 Unity 实机验收。

关键词：优势判定、优势检定、两次取最高、高地、弓箭命中、动物交谈术、驯服、情境条件。

## 一 已确认的设定

**优势判定：角色达成某些条件后，在对应情境的判定中进行两次投掷，取最高值作为本次判定结果。**

优势与具体条件及判定类型关联。例如，攻击命中的优势作用于命中判定，动物沟通带来的优势作用于驯服判定。

| 已确认的例子 | 获得优势的条件 | 作用的判定 |
| --- | --- | --- |
| 高点射击 | 弓箭手站在高点 | 攻击的命中投掷判定，两次取最高值 |
| 沟通后驯服 | 先使用动物交谈术，且沟通得不错 | 驯服动物的判定，两次取最高值 |

按后续“开始实现”的确认，第二、三节的首版范围已落实；第四节的其他情境仍仅为扩展示例。当前实现契约以所属 ForAI 模块与源码为准。

## 二 首版通用规则

1. **先检查条件，再投掷。** 每个优势来源明确适用的行动、角色、目标和有效期；符合条件时，普通的一次判定变成两次取最高。预览与实际执行使用相同条件。
2. **两次使用相同规则。** 两次投掷独立，使用同一种骰子、同一难度与同一组修正；两次之间不扣费、不改变目标状态。最高值确定后，统一结算一次成功或失败。
3. **一次行动只结算一次。** AP、弹药、冷却、材料及游戏时间仍按一次行动处理；命中后的伤害、奖励或驯服归属只执行一次。优势不是额外攻击，也不额外重掷伤害、暴击或附加效果。
4. **多个优势来源不增加投掷次数。** 同一次判定同时满足多个条件时仍只投两次，保留全部来源用于说明；不自动升级为三次、四次或无限重投。
5. **只影响指定判定。** 命中优势不绕过射程、视线、弹道拦截或目标合法性；多发技能逐发检查各自的命中优势，单发中两次投掷仍只决定这一发是否命中。
6. **相同值正常处理。** 两次相同就采用该值，不补投。优势不额外赋予大成功、大失败或暴击含义，也不自动新增“劣势判定”规则。

如果普通单次成功率为 `p`，两次独立且任一次成功即可通过时，优势成功率为 `1 - (1 - p)²`。例如 30% → 51%、50% → 75%、70% → 91%；0% 与 100% 保持不变。这是概率关系，不是固定增加命中百分点，后续平衡需据此评估。

## 三 两个首批情境

### 高点射击

- 相对于本次目标判断高点，使用同层双方实际站立面的高度；天然地形与营造高台使用相同规则。站在高处但目标同样高或更高，不获得该来源的优势。
- 门槛复用现有高地级别，达到至少一级（当前配置 1 米）时生效；更高的高差不增加骰子数量。首版仅作用于敌方目标的弓系技能（`target='enemy'`、`proficiency='bow'`），包含现有合法容器攻击；其他武器／法术暂不扩展。
- 弓系优势替换同一高地来源的命中百分点奖励，保留已有射程收益。其他攻击的旧高地规则保持；多目标按每个目标分别判断。

### 动物沟通后驯服

- “沟通得不错”对应当前动物交谈的成功结果，不另引入关系评分或成功等级。
- 优势绑定本次沟通的同一只动物，全队共享，下一次实际驯服尝试无论成败都消费；预览和不合法的操作不消费。
- 沿用当前沟通结果的防重复获取和存档语义，换人、换方式、关闭重开不能刷取更多次数；未消费结果保留到实际尝试，不增加时间过期。旧档正值沟通结果在本版按优势解释，不新增存档字段。
- 成功沟通原有的正向驯服概率修正替换为优势；动物亲和、魅力、物种难度等基础公式继续独立计算。失败沟通仍保留既有负向修正，不转成劣势。

## 四 可扩展的情境示例

以下只用于说明设计方向，尚未确认加入内容，也不表示相关系统已经实现。

| 条件示例 | 可以获得优势的判定 |
| --- | --- |
| 事先找到并理解机关的结构线索 | 对该机关的拆解或解除判定 |
| 掌握与谈判对象有关的有效情报 | 对该对象、该话题的说服判定 |
| 队友成功吸引守卫注意 | 趁该次分心通过其警戒范围的潜行判定 |

新增条件时，需要写清楚“谁获得、对谁或什么生效、适用于哪种判定、何时失效”，避免把局部准备收益变成所有行动的永久优势。

## 五 实现入口与表现

具体触发规则由业务模块持有，共享判定模块只负责抽取与选取结果。

| 入口 | 已接入内容 |
| --- | --- |
| [HeightAdvantage](../Lua/Game/Battle/HeightAdvantage.lua)／[ProjectileCombat](../Lua/Game/Battle/ProjectileCombat.lua) | 逐目标高地优势、预览、弹道与命中结算；当前契约见[战斗模块](../ForAI/Business/Battle.md)。 |
| [AnimalRules](../Lua/Game/Animals/AnimalRules.lua)／[AnimalSpeech](../Lua/Game/Animals/AnimalSpeech.lua) | 沟通来源、实际驯服率、一次消费；世界对话、探索和战斗入口共用，见[动物模块](../ForAI/Business/Animals.md)。 |
| [CheckRoll](../Lua/Game/CheckRoll.lua) | 按原随机流与精度抽取两次，转换为高值、去重来源并选最大；保留阈值、两次结果和实际概率。 |
| [DiceChecks](../Lua/Game/Presentation/DiceChecks.lua)／[DiceRollCtr](../Lua/UI/Panel/DiceRollCtr.lua)／[BattleLog](../Lua/Game/Battle/BattleLog.lua) | 已结算结果的两轮演出及战斗日志；具体数据约定见[骰子与优势](../ForAI/Business/Dice.md)。 |

原整数百分骰 `r ∈ [0,99]`、成功条件 `r < chance`，转换为高值 `v = 100 - r`。按离散随机值求出实际单次成功率 `p` 后，条件为 `v > 100 - p`，两次取最高。驯服保留原百分位整数阈值；探索容器保留百分位严格比较，并处理浮点乘法误差，不能把恰好相等的值判成成功。

执行前的命中／驯服预览说明优势与实际概率；骰子按两轮顺序播放，最后展示两值并突出最高值，战斗通过日志显示。顺序播放使百分位驯服每轮四颗骰子不超过现有六颗上限。提示与模板已按[本地化约束](../ForAI/Framework/Localization.md)接入；命中预览同时计入弹道通过率。

## 六 验证与剩余范围

首版外的范围：其他武器、机关／说服／潜行等来源、劣势及抵消规则。现有实现未为这些示例新增玩法。

本轮已执行的定向检查覆盖：

- 普通判定一次、优势判定两次，选择最高值；两次相同不补投，多个来源按最终确认规则合并。
- 概率方向与精度正确，0%／100%及阈值相等时的结果不被转换改变。
- 高点／平地／低点及不同目标分别判断；命中优势不改变拦截、伤害、暴击或行动消耗。
- 沟通优势只影响正确动物，实际尝试消费一次；预览、不合法操作、换人、重开与旧正值状态兼容。真实存档读写未在本轮重验。
- UI 显示与实际结果一致；一次行动最多产生一次伤害、归属或奖励结算，快速揭晓不重投。
