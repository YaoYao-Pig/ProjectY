## 二 直射与抛射的独立需求

### 原始目标

| 类型 | 设计规则 | 适用例子 |
| --- | --- | --- |
| 直射 | 弹道路径上的物体能够抵挡；贴近的对象不阻挡 | 弩、枪械、部分法术 |
| 抛射 | 靠近的物体能够抵挡；一格之外的物体不阻挡 | 弓箭、部分法术 |

### 当前实现与差距

**状态：已实现配置与规则，离线定向检查通过；Unity 实机表现尚未验收。**

- 已确认距离相对于攻击者，只检查弹道经过的中间格。起点及目标不会阻挡自己；途中存活友军、敌军和动物均参与阻挡，完整多格占位有效，倒地角色不阻挡。
- `CombatSkillTable.trajectory` 支持 `sight`（默认，沿用原地形视线）、`direct`（直射，忽略相邻一格、检查后续路径）、`lobbed`（抛射，只检查相邻一格）。枪械点射／连射已配直射，弓箭射击／穿叶箭／贯风箭已配抛射；法术可逐条设置，未指定的法术保持 sight。
- 地形／陈设／工事／容器继续使用自身的阻挡属性和高度。木墙能挡，栅栏仍不挡；工事拆除／容器破坏后的变化即时反映。在场 NPC、未参战动物及未清除工具障碍也进入区域弹道占位查询。
- 阻挡时无法攻击该目标，不命中挡路对象、不消耗 AP／弹药／冷却。玩家、AI、角色目标、探索／战斗容器和散射追加目标使用同一校验；旧独立棋盘也支持两种新弹道。
- 探索 `CanSee` 保留完整视线；弹道借助 `CanTrace` 筛选中间格。多层几何保留起点／终点楼板阻挡，未开放多层战斗。容器仍须在当前视野且与攻击者同层。
- 战斗 HUD、探索技能说明和技能图谱显示弹道规则。当前没有独立弩的运行时武器条目，新增弩技能可使用 direct；组件动态切换弹道类型尚未接入。

对应入口：[弹道规则](../Lua/Game/Battle/SkillTrajectory.lua)、[战斗校验](../Lua/Game/Battle/BattleSystem.lua)、[地图几何](../Lua/Game/MapArea/MapAreaLayout.lua)、[容器攻击](../Lua/Game/Loot/ContainerCombat.lua)、[技能源表](../Config/Tables/Adventure/CombatSkillTable.json)。完整契约见 [ForAI 战斗](../ForAI/Business/Battle.md)。

### 职业与触媒的已确认方向

2026-10-13 确定：**保留职业划分，玩家主动选择学习技能，并可自由转职学习其他职业的技能来组成搭配。装备不设职业限制，角色的装备准入由属性条件决定；法术能否释放还要检查当前是否具有有效触媒。**

| 层次 | 负责决定什么 | 已确定的规则 |
| --- | --- | --- |
| 职业与技能学习 | 学习路线与可选择的技能 | 有明确职业，玩家主动选学；允许跨职业学习并组合技能。职业切换与既有技能的组合应分开表达，不能只靠当前职业名称判断全部可用技能。 |
| 装备适配 | 角色能否使用某件装备 | 不设职业白名单；装配时按排除装备加成后的角色属性作硬门槛。旧档装备不强行卸下，装备后属性不足沿用原武器弱化规则。 |
| 技能掌握 | 角色是否学会法术 | 触媒只提供释放条件，不自动让角色学会对应职业的法术。现有装备授予的技能是另一种来源，需与角色学会的技能区分。 |
| 施法触媒 | 已学法术当前能否施放 | 法师只持普通剑且没有有效触媒时，无法释放需要触媒的法术；触媒缺失属于当前使用条件不足，不应删除已学技能。 |
| 配件与专精 | 怎样扩展施法组合 | 首版铁剑／骑士剑可安装适配器 93，并要求奥术兵装专精 301；支持奥术触媒。法杖提供原生触媒；主手优先、副手备选，后续类别继续配表扩展。 |

下列例子说明学习与使用条件的分工，均以其他施放条件已满足为前提：

| 角色状态与装备 | 预期结果 |
| --- | --- |
| 已学法术，只持普通剑，没有有效触媒 | 能持剑战斗，该法术不可施放，并说明缺少触媒。 |
| 已学法术，剑装有适用触媒配件，所需专精条件已满足 | 可以通过这把剑施法；角色仍保留剑的装备身份。 |
| 没学过该法术，拿着法杖或带触媒的剑 | 不会仅因获得触媒而掌握该法术；装备自身授予的技能另按其来源处理。 |
| 通过跨职业学习掌握法术，并持有适用触媒 | 可把该法术与其他职业技能组合使用。 |
| 已学法术，随后卸下触媒配件且无其他有效触媒 | 法术保持已学，当前不可施放；恢复触媒后再按条件检查。 |

**当前实现：**[GrowthSystem.Learn](../Lua/Game/Progression/GrowthSystem.lua) 已按职业课程、角色等级、属性、前置及学习机会主动学习；[ProfessionRules](../Lua/Game/Progression/ProfessionRules.lua) 解释职业与课程。[EquipmentRules](../Lua/Game/Equipment/EquipmentRules.lua) 分别处理装配硬门槛和施法触媒，技能身份保留；[BattleSystem](../Lua/Game/Battle/BattleSystem.lua) 的行动预算和探索技能入口共用装备条件检查。图谱与手记区分已掌握、固有来源和当前缺触媒原因。

职业课程、属性要求、技能触媒需求、武器／配件的触媒能力及所需专精已分别配置；战斗、探索和 UI 共用同源规则。技能学习不因当前缺触媒而被禁止。

首版为探索期免费转职、初始一次学习机会、等级表继续提供升级机会，空目录保留机会。初始职业赠送对应准备技能，随后转职需要主动学习其他职业技能；旧随机候选不再作为正常学习入口。职业、技能、专精、配件与消耗品随 v5 存档保存，旧版明确迁移。分职业等级、更多触媒种类和后续平衡调整仍待扩展。

### 六边形战场与战前部署的已确认方向

2026-10-13 确定：**放弃两边各 3×3 的旧阵地方案，保留当前六边形战场。在正常战斗之前增加一次独立的战前部署回合，该回合有 AP 限制，可以使用各职业不同的准备技能及道具。** 探索与战斗共用地图的现有基础继续保留。

战斗流程为：遭遇成立 → 战前部署回合 → 正常战斗回合 → 战后结算／恢复探索。

| 项目 | 已确定的规则 | 首版实现 |
| --- | --- | --- |
| 战场 | 延续共享六边形战场、地形、射程与弹道 | 默认距本人初始格两格内移动，半径配表；保留原通行与占格检查。 |
| 部署时机 | 正常开打前一次部署回合 | 仅己方按速度／ID行动；敌人已布置但本阶段不行动，保留原视野信息。 |
| AP 限制 | 部署回合具有行动预算 | 每角色独立模板 AP，沿用一次普通移动与主要行动额度；正式第一轮重新给予 AP。 |
| 准备技能 | 各职业有不同准备技能 | 战意、警戒、奥术凝聚、临时加固；已学后允许跨职业使用，技能种类和阶段分别配置。 |
| 道具 | 部署回合允许使用道具 | 急救包和备战药剂自用，消耗配表 AP 与真实库存；正式战斗也可用。 |
| 阶段结束 | 全员结束后进入正常战斗 | 部署不推进效果／冷却／世界回合，准备增益在角色首次正式行动期间有效，再按回合结束计时。 |

**当前实现：**[BattleSystem.Start／StartArea](../Lua/Game/Battle/BattleSystem.lua) 先进入 deployment，结束后进入 combat。[技能源表](../Config/Tables/Adventure/CombatSkillTable.json) 的 `skillKind` 区分 active／preparation／item，`contexts` 定义 life／battle／preparation 使用阶段；`action` 仍为主要／次要行动。[战斗 HUD](../ForAI/Business/BattleHUD.md) 已显示部署状态、准备技能、道具名称／数量及实际使用按钮。

准备技能和道具使用统一预算与效果预校验，失败不消费资源，物品不变成永久技能。初始背包、商店和掉落提供实际道具／配件；真实 UI 和 Play 命令已走通部署至胜利结算，详见 [验收记录](GameplayFoundationIteration.md)。
