# 职业 触媒与战前部署迭代验收

开始日期：2026-10-13。用户已授权自由规划可配置的首版规则、使用子代理、多轮迭代与完整验收；新增模型如有需要使用 Blender MCP。设计来源为 [玩法差距清单](GameplayGapAudit.md)。

## 交付链路

角色选择研习职业 → 主动学习与跨职业组合 → 按属性装备武器／防具 → 通过法杖或带专精的触媒配件施法 → 遭遇后进入 AP 受限的部署回合 → 使用职业准备技能／道具 → 正式战斗 → 战后搜刮、补给与存档。

当前共享六边形战场继续使用；双边 3×3 阵地方案已放弃。成长、装备、战斗及库存的可变状态继续归 C# Data，Lua 解释配置并执行命令。

## 首版默认规则

| 领域 | 规则 |
| --- | --- |
| 职业 | 战士、游侠、法师、巧匠；探索间隙免费切换研习职业，保留已学技能与曾加入职业。 |
| 学习 | 消费现有学习机会主动选择合格技能；初始增加一次机会，升级机会沿等级表；空技能池不消耗机会。门槛为当前职业、角色等级、属性与技能前置。 |
| 初始准备技能 | 初始职业授予对应准备技能；后续转职不会自动赠送新职业准备技能，需要学习。已学准备技能允许跨职业组合。 |
| 职业进度 | 首版技能门槛使用角色等级；不引入分职业经验或分职业等级分配。 |
| 装配 | 没有职业白名单；按排除装备加成后的角色属性检查装配门槛。已有装备不因存档迁移被卸下，装备后属性不足仍沿原武器弱化规则。 |
| 触媒 | 主手优先，副手其次；法杖原生提供奥术触媒。普通剑安装触媒适配器并掌握“奥术兵装”专精后可以施法。触媒不自动授予已学习法术。 |
| 专精 | 奥术兵装使用持久化天赋节点 301，等级与点数条件配表；装备、学习和施放分别校验。 |
| 部署 | 正常战斗前一次，仅己方按速度／ID行动；每角色独立模板 AP，默认在初始格两格内移动，沿用单次普通移动与主要行动额度。敌人本阶段不行动。 |
| 阶段 | 部署不推进区域世界回合、效果时长或敌方行动；全员结束后进入正式第一轮并重新给予 AP。 |
| 准备技能 | 新种类，与主要／次要行动、使用阶段分别配置；战意、警戒、奥术凝聚、临时加固分别提供首轮力量、速度、智力、防御增益。 |
| 道具 | 急救包与备战药剂先支持自用，可在部署／战斗使用；消费 AP 与真实共享库存，不把物品效果永久学成技能。 |
| 获取 | 急救包、备战药剂、触媒适配器进入初始背包、商店与掉落；重开与购买遵守既有库存规则。 |
| 外观 | 复用已制作的医疗包、药瓶、符文模型和图标，定向同步实际资源引用及剑的配件挂点。 |

## 验收范围

1. 职业切换、主动学习、跨职业已学保留、前置／属性／等级不足、重复学习和机会不足。
2. 角色成长及职业状态的存档往返；旧版存档显式迁移；损坏与未知版本拒绝且保持当前数据。
3. 属性门槛边界，装备／卸装／副手／双手互斥，初始装具与招募预检，满包失败不丢失状态。
4. 法师持普通剑不能施法；法杖恢复施法；适配器与专精必须同时满足；副手触媒、组件效果、敌方原生触媒、探索容器攻击均使用同一规则。
5. 部署 AP 与移动范围，普通攻击的阶段限制、准备技能效果跨阶段、敌方等待、每角色结束、正式回合的 AP／行动顺序与世界时钟。
6. 道具数量、AP、使用阶段、重复点击和失败事务；初始物资、购买、掉落、背包及存档保存实际数量。
7. 使用真实 Prefab 与 UI 命令验证职业学习、武器改装、技能不可用原因、准备技能、道具及结束部署；检查界面缓存、分页、暂停恢复。
8. 真实场景中完成探索 → 遭遇 → 部署 → 战斗 → 结算；检查 Console 新增错误并记录结果。

## 使用与复验

- 角色手记 → 天赋与技能：查看当前职业、展开切换研习职业，再消费学习机会选择课程。图谱显示来源／条件，法术会提示是否缺触媒。
- 背包／工坊：按属性装备法杖或剑；剑可安装触媒适配器，掌握奥术兵装后成为触媒。副手触媒同样有效。
- 遭遇后先进行部署：每人可调整站位、使用职业准备技能和道具，点击“结束部署”；所有人结束后进入第一轮。道具按钮直接对自己使用。
- 真实隔离数据验收宿主为 [gameplay_foundation_editmode.cs](../Tools/Tests/gameplay_foundation_editmode.cs)；使用独立 PreviewScene、LuaEnv 和临时存档。Play 先在新测试会话执行 [学习检查](../Tools/Tests/gameplay_foundation_play.lua)，再通过 Unity MCP 执行 [场景命令检查](../Tools/Tests/gameplay_foundation_play_commands.cs)，后者有 150 秒／240 命令上限并自行退订。
- 界面截图由 [预览脚本](../Tools/Tests/gameplay_foundation_preview.cs) 使用真实 Prefab 生成并目视检查：[职业学习](Previews/GameplayFoundation/professions.png)、[部署与道具](Previews/GameplayFoundation/deployment.png)。这是界面隔离预览，场景玩法另由 Play 记录验证。
